# AvTech ISABI Autollenado

1. Abre `chrome://extensions` o `edge://extensions`.
2. Activa **Modo desarrollador**.
3. Elige **Cargar extensión sin empaquetar** y selecciona esta carpeta.
4. En AvTech abre **Notaría > Expedientes ISABI** y pulsa **Copiar para portal**.
5. Abre el formulario ISABI, pulsa la extensión, pega el contenido y elige **Completar formulario visible**.

La extensión únicamente rellena controles visibles. No adjunta documentos, no calcula el impuesto y nunca presiona el botón de registro. Verifica todos los datos antes de presentar el trámite.
